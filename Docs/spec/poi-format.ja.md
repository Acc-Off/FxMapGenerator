# POI の形（POI のフォルダ、poi-styles.json）

地図に描く POI（施設名、マーカー、アイコンなど）と、その見た目（POI スタイル）のファイル。

- コードの正: `src/FxMapGenerator.Core/Poi/PoiData.cs`（読み込み）と `PoiFiles.cs`（画面が書くとき）。
- プロジェクトの `poi` が POI のフォルダ、`poiStyles` が POI スタイルのファイル。

| 設定 | null のとき（同梱のもの） |
|---|---|
| `poi` | `data/poi/` の 2 つのファイル |
| `poiStyles` | 同梱の POI スタイルだけ（`data/poi-styles.json`） |

- `data/poi/` の 2 つのファイル:
  - `highway-markers.json`: Highway One マーカー A〜Z の 26 個。
  - `colored-dots.json`: 色付きの丸 5 個。
  - どちらも、ロックつき。
  - 位置・色と、色付きの丸の大きさは、postal code map（Virus_City）の地図の画像から取ったもの。
- 同梱の POI スタイルは、「Highway One マーカー」「色付きの丸」「施設名」。

ファイルの決まり:

- UTF-8 の JSON。手で直すこともあるので、コメントと末尾のカンマは使ってよい。
- 読むときに、中身を確認する。おかしな所があれば、理由をすべて挙げて止める。
- 位置はゲームの x・y（m）、長さは m、色は `#rrggbb`。

名前とラベルは、別のもの。

- 名前（フォルダ・まとまり・POI・POI スタイルの `name`）:
  画面の一覧と検索に使う、利用者の言葉の文字 1 つ。地図には描かない。
  - 同梱のもの（同梱のまとまり・POI スタイル）だけは、`{"en", "ja"}` で英語と日本語の名前を持ち、
    画面の言語で出す。
  - 同梱のものをプロジェクトにコピーするとき（最初の保存、POI スタイルの複製）は、
    その時の画面の言語の名前 1 つになる。以後は、その名前のまま。
- ラベル（POI の `label`）: 地図に描く文字。
  地図の言語（プロジェクトの `maps.atlas.languages`）ごとに持つ。

## 画面で編集するとき

- 地図の編集タブの「POI」で、フォルダ・まとまり（画面では「グループ」）・POI と、POI スタイルを編集する。
  保存するまで、ファイルは変わらない。
- 書くのは、中身の変わったファイルだけ。
  - 手で書いたファイルは、画面で変えない限り、そのまま残る。
  - 画面で変えたファイルは、アプリの形で書き直すので、コメントは消える。
  - 消したまとまりのファイルと、空になったフォルダは消す。
  - `.json` 以外のファイルには触れない。
- 画面で作ったフォルダとまとまりのファイル名は、付けた名前から作る。
  Windows で使えない文字は `_`。同じ名前があれば、「 (2)」…。
  名前を変えると、ファイル名とフォルダ名も変わる。
- 地図の上に置いた POI は、名前なし、ラベルは英語「New POI」で始まる。
  日本語の地図を作るときは、日本語「新しい POI」も。
- 画面は、日本語の地図を作らないプロジェクトでは、日本語のラベルの欄と、ラベルの言語の切り替えを出さない。
  日本語の地図を作らないとは、アトラス地図を作らないか、`maps.atlas.languages` に `ja` がないこと。
- 実行（プロジェクト画面）は、始めたときに、POI のフォルダと POI スタイルのファイルを、
  `logs/run-<時刻>/inputs/` にコピーして読む。POI スタイルが指定している PNG も。
  文字・セル描画・縮小タイルのステップが残っている間は、画面から保存できない。

**最初の保存**

- `poi` が null のまま最初に保存すると、プロジェクトファイルの横に `poi/` を作る。
  名前が使われていれば、`poi-2/` …。
- 同梱のまとまりをコピーして、変更を書き、プロジェクトの `poi` をそこにする。
  まとまりの名前は、その時の画面の言語の名前 1 つにする。
- 同梱のままなら、何も作らない。
- 自分の POI スタイルを初めて保存したときも、同じく `poi-styles.json` を作って、`poiStyles` にする。

**読み込み（CSV / JSON）**

- CSV は、1 行目に列の名前が要る。カンマ区切り、UTF-8。
  - `x`・`y` は必須。
  - `label`（英語のラベル）・`labelJa`（日本語のラベル）・`name`（名前）・`color`・`size` は任意。
  - ほかの列は読まない。
- JSON は、まとまりのファイルか、POI の配列。
  `label` は、`{"en", "ja"}` か、英語のラベルの文字。
- 地図の範囲外の行と、読めない行は、理由を出して読まない。

## POI のフォルダ

ディスクのフォルダが、そのまま POI のフォルダになる。
フォルダの中の `.json` ファイル 1 つが、POI のまとまり 1 つになる。
まとまりやフォルダは、ファイルやフォルダのまま、ほかのプロジェクトへコピーできる。

```
poi/                      ← プロジェクトの poi
  highway-markers.json    ← まとまり
  colored-dots.json
  店/                     ← POI のフォルダ（入れ子にできる）
    _.json                ← フォルダの設定（なくてもよい）
    コンビニ.json
    服屋.json
```

- フォルダの中の `.json` は、すべて読む。`_.json` はフォルダの設定、ほかはまとまり。
  `.json` 以外のファイルは読まない。
  POI スタイルのファイルは、このフォルダの外に置く。
- 並び順は、フォルダの中のまとまりとフォルダを、`order` の小さい順。
  同じなら、名前（ファイル名・フォルダ名）の順。
  まとまりの中の POI は、ファイルの順。
  この並び順を、画面の並び、描く順、文字の場所を先に取る順に使う。
- まとまりやフォルダの名前を書かないときは、ファイル名（`.json` を除く）・フォルダ名を名前にする。

### まとまり（`<名前>.json`）

```json
{
  "format": 1,
  "name": "コンビニ",
  "order": 0,
  "style": "facility",
  "show": { "atlas": true, "roadmap": true },
  "visible": true,
  "locked": false,
  "points": [
    { "id": "1", "name": "駅前の店", "label": { "en": "24/7", "ja": "24/7" }, "x": 25.0, "y": -1350.0 }
  ]
}
```

| 欄 | 既定 | 中身 |
|---|---|---|
| `name` | ファイル名 | 名前（文字 1 つ） |
| `credit` | null | 書き出しのクレジットに入れる文 |
| `order` | 0 | 並べる順（同じフォルダの中で小さい順。整数） |
| `style` | null | 中の POI の POI スタイル。null はフォルダから |
| `show` | null | 中の POI を描く地図。null はフォルダから |
| `visible` | true | false なら、中の POI をすべて描かない |
| `locked` | false | true なら、中の POI をすべて画面で動かせない・消せない |
| `points` | | POI の一覧（下の表） |

- `name`: 画面の一覧に出し、地図には描かない。同梱のまとまりは `{"en", "ja"}`。
- `credit`: このまとまりの POI が、その地図に 1 つでも出るときに入れる
  （`project-format.ja.md` の「クレジット」）。
  まとまりのファイルだけにある。`_.json` にはない。
- `show`: `atlas`（アトラス地図）、`roadmap`（道路地図）。書かない欄は、既定の値。

POI（`points`）:

| 欄 | 既定 | 中身 |
|---|---|---|
| `id` | | POI の id（ファイルの中で 1 つ） |
| `name` | "" | 名前（文字 1 つ） |
| `label` | なし | 地図に描く文字（ラベル） |
| `x`、`y` | | 位置（地図の枠の中） |
| `style` | null | POI スタイル。null はまとまりから |
| `show` | null | 描く地図（まとまりと同じ形）。null はまとまりから |
| `color` | null | 色（POI スタイルの色の代わり） |
| `size` | null | 大きさ m（POI スタイルの大きさの代わり） |
| `visible` | true | false なら描かない |
| `locked` | false | true なら画面で動かせない・消せない |

- `name`: 一覧と検索に使い、地図には描かない。空のときは、一覧にラベルを出す。
- `label`: 地図の言語ごと（`en`・`ja`）。
  - その言語のラベルが空なら、`en` のラベルを、`en` のフォントで書く。同梱の A〜Z は `en` だけ。
  - 文字を描かない POI（色付きの丸）は、書かない。
- `color`: 色付きの丸は、5 個とも色が違う。
- `size`: 色付きの丸は、57.3 m と 58.7 m がある。

### フォルダの設定（`_.json`）

```json
{ "format": 1, "name": "店", "order": 0, "style": "facility", "visible": true, "locked": false }
```

- 欄は、まとまりの `points` 以外と同じ。`name` の既定は、フォルダ名。
- `poi` のフォルダそのものにも置ける（全体の既定になる）。
- 画面は、次のフォルダに `_.json` を書く。
  設定のあるフォルダと、ファイルがなくなると消えてしまう空のフォルダ。

### 引き継ぎ

- `style` と `show` は、POI に書いてあれば、それを使う。
  なければ、まとまり、入っているフォルダ、その上のフォルダ…の順に、いちばん近いものを使う。
  - どこにもない `show` は、既定（アトラス地図だけ: `atlas` true、`roadmap` false）。
  - どこにも `style` がない POI は、誤り。
- `color` と `size` は、POI になければ、POI スタイルの値。
- `visible` と `locked` は、まとまりとフォルダの方が強い。
  - 隠したまとまり・フォルダの中は、すべて描かない。
  - ロックしたものの中は、すべてロックつき。
  - 中の 1 つだけを隠す・ロックすることはできる。

### ほかのプロジェクトへのコピー

- まとまりのファイルかフォルダを、コピーするだけでよい。
- 使っている POI スタイルがコピー先にないときは、読み込みで理由を出して止める。
  同梱の POI スタイルは、どのプロジェクトにもある。
- 同梱の POI は、`poi` が null のときだけ読む。
- 自分の POI のフォルダに同梱の POI も入れたいときは、リポジトリの `data/poi/` の
  `highway-markers.json`・`colored-dots.json` を、そのフォルダにコピーする。
  `credit` も一緒に付いていく。名前は `{"en", "ja"}` のまま、画面の言語で出る。

## POI スタイル（poi-styles.json）

- 同梱の POI スタイル（`data/poi-styles.json`）は、どのプロジェクトでも使える。
- プロジェクトの `poiStyles` のファイルは、それに自分の POI スタイルを足す。
- 同梱のものと同じ id は、誤り。
  同梱の見た目を変えたいときは、別の id で作り、まとまりの `style` をそれにする。
  画面の「複製」が、そうする。

```json
{
  "format": 1,
  "styles": [
    { "id": "shop", "name": "店", "look": "icon", "icon": "store", "color": "#303060", "size": 24,
      "weight": "bold", "outline": "#ffffff", "outlineWidth": 3, "showLabel": true },
    { "id": "garage", "name": "ガレージ", "look": "icon", "image": "poi-icons/garage.png",
      "color": "#000000", "size": 30 }
  ]
}
```

| 欄 | 既定 | 中身 |
|---|---|---|
| `id` | | POI スタイルの id（同梱のものも合わせて 1 つ） |
| `name` | | 名前（文字 1 つ。画面にだけ出す） |
| `look` | | 描き方 |
| `icon` | null | `icon` のときのアイコン。MDI の名前 |
| `image` | null | `icon` のとき、MDI の代わりに描く PNG |
| `color` | | 色。POI の `color` が優先 |
| `size` | | 大きさ m。POI の `size` が優先 |
| `weight` | `normal` | 文字の太さ: `normal`、`bold` |
| `outline`、`outlineWidth` | null、0 | 縁取りの色と幅 m |
| `badgeColor` | null | `badge` の丸の色 |
| `showLabel` | false | `dot` と `icon` の右に、POI のラベルも書く |
| `labelSize` | null | 横に書くラベルの大きさ m。null は大きさの 0.6 倍 |

- `name`: 同梱の POI スタイルは `{"en", "ja"}`。
- `look`:
  - `text`: ラベルを文字で。
  - `badge`: 塗った丸の中にラベル。
  - `dot`: 塗った丸だけ。
  - `icon`: アイコン。
- `icon`: MDI（Material Design Icons）の名前。`data/mdi-icons.json` にあるもの。
  例 `hospital-box`、`store`、`gas-station`。
- `image`: POI スタイルのファイルのフォルダの中のパス。`/` 区切りで、外へは出られない。
  画面は、`poi-icons/` にコピーする。
  `icon` と `image` は、どちらか一方。
- `color`: 文字、丸、MDI のアイコンの色。`badge` では、中の文字。PNG には、色を付けない。
- `size`: 文字の em、丸の直径、アイコンの高さ。
- `weight`: `bold` は、横に書くラベルにも効く。
- `outline`、`outlineWidth`: 文字、丸、MDI のアイコンのまわり。
  アイコンの後ろに丸があるときは、丸のまわり。
- `badgeColor`: `badge` では、文字は `color`。
  `icon` では、アイコンの後ろに塗った丸を描く。直径は、アイコンの 1.5 倍。
- `showLabel`: `text` と `badge` では、誤り。
  色は、POI の色。後ろに丸のあるアイコンは、丸の色。

フォントは、ほかのラベルと同じく、地図のスタイルのものを使う。POI スタイルでは選ばない。

同梱の POI スタイル:

| id | 見た目 |
|---|---|
| `highway-marker` | 赤い太字（#e02020）に、白い縁取り 5 m。大きさ 65 m |
| `colored-dot` | 塗った丸（色と直径は POI ごと）に、白い縁取り 2 m |
| `facility` | 施設名の文字（#202020、12 m、白い縁取り 3 m） |

- `highway-marker`: 元の地図の画像の文字は、45.78 m に当たる。
  丸に白い文字にするときの丸の色は、#d42a2a。
- `facility`: 同梱の POI では、使っていない。

アイコンのデータ `data/mdi-icons.json`:

- npm の `@mdi/svg`（Pictogrammers の Material Design Icons、Apache License 2.0）から作ったもの。
  使われなくなったアイコンは除く。
- アイコンは、24×24 の枠の path 1 本。`size` の高さに合わせて描く。
- 版は、ファイルの `version`。作り方は、`development.ja.md`。

## 地図への描き方

- アトラス地図（`show.atlas`）と道路地図（`show.roadmap`）に描く。
- 文字の置き場所を決めるときは、番地と同じく、先に場所を取る。地区名や通り名は、そこを避ける。
  取る場所は、アイコンは大きさと縁取りの四角、横のラベルはその四角。
- 描く順は、道の後に、番地 → POI → 地区名 → 通り名。
- POI は、z8（1 ブロック 1,024 px）でスタイルの `minPixels` より小さいものは、描かない。
  横のラベルも同じ。
- ミニマップ（ytd）は、プロジェクトで選んだ地図のタイルを、そのまま使う。
  その地図に描いた POI は、ゲーム内の地図にも出る。
  ゲームの本物の blip と、同じ所に重なることがある。
- 地図に描く値が変わると、文字の置き直しと、その POI のまわりのセルの描き直しになる。
  地図に描く値は、ラベル、位置、見た目、PNG の中身、出す地図、表示。
- 名前（POI・まとまり・フォルダ・POI スタイル）、`credit`、注釈を直しただけなら、何も作り直さない。
