# 名前表（GXT2）の読み方

通り名と地区名を英語・日本語で出すのに読む、GTA V の文字の表。

- 読むコード: `src/FxMapGenerator.GameData/Text/Gxt2File.cs`
- 書くコード: `src/FxMapGenerator.Core/GameFiles/GameFilesOutput.cs`

## ファイル

- 読むのは、`data\lang\<言語>_rel.rpf` と、DLC の `<言語>dlc.rpf`（と `<言語>.rpf`）の中の `*.gxt2`。
- 読む言語は、`american`（英語、キー `en`）と `japanese`（日本語、キー `ja`）。
- 同じキーが複数のファイルにあれば、アーカイブの索引の順で、後のものが残る。
- 形: `2TXG`、u32 の数、その数だけの組、そのあとに NUL で終わる UTF-8 の文字列。
  組は、u32 のキーと、u32 のファイルの頭からの位置。

## キー

- 通り名: `GET_STREET_NAME_AT_COORD` が返すハッシュ（採取の `dict street` の行）と、
  ynd のノードの通り名のハッシュ。
  符号付きで書かれていても、32 ビットの符号なしとして扱う。
- 地区名: `GET_NAME_OF_ZONE` が返す地区のコード（例 `LEGSQU`）の joaat。
  見つからなければ、小文字にしたコードの joaat。
- joaat: Jenkins の one-at-a-time を、UTF-8 のバイトにそのままかけたもの。小文字にしない。

## 作業フォルダに書くもの（`game/`）

`names.json`。道のノードの通り名と、採取が出会った通り名・地区。

```json
{
  "streets": { "13393056": { "en": "Grove St", "ja": "グローブ・ストリート" } },
  "zones": { "LEGSQU": { "en": "Legion Square", "ja": "リージャン・スクエア" } }
}
```

- 通りは、車のノードの通り名のハッシュと、採取の通り名のハッシュを合わせたもの。
- 地区は、採取が出会ったもの。
- キーの順は、数の小さい順。地区は、コードの文字の順。
- ある言語に文字がなければ、その言語の項目を書かない。全部の言語になければ、空の `{}`。
- ノードの通り名のハッシュには、どの表にもないものが多い（名前を出さない道）。
- 採取の名前は、範囲のうち、道の採取があるブロックのものだけ。
- 採取が新しくなると、ゲームファイルのステップは読み直しになる。
